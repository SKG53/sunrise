# SUNRISE — SEO Deep Dive

**Site:** https://www.savorsunrise.com
**Date:** 2026-08-26
**Sources:** Lovable SEO scanner, Semrush (US database), repo inspection. Google Search Console is **not** connected to this project, so no first-party click/impression data was available.

---

## 1. Executive summary

The technical foundation is genuinely good — SSR, clean canonicals, a dynamic sitemap, JSON-LD on the pages that matter, correct noindex on the pages that should be hidden. The site is not being held back by broken plumbing.

It is being held back by three things:

1. **The site has almost no topical surface area.** 134 keywords, ~50 visits/month estimated. Everything that ranks is a brand-name accident ("sunrise drinks", "sunrise seltzer"). Nothing ranks for the category — "thc seltzer" (14,800/mo), "thc drinks" (74,000/mo), "thc drinks near me" (12,100/mo).
2. **The viewport is locked to a fixed desktop width (`width=1100`).** This is the single most consequential technical issue on the site. Google indexes mobile-first.
3. **Authority Score 8/100 with a spammy link profile.** 22 referring domains, several of which are PBN/link-farm junk.

Priority order: fix the viewport → fix the favicon and the 302s → build category and local pages → clean up the backlink profile.

### Issues found

#### P0 — Fixed-width viewport (mobile-first indexing risk)

`src/routes/__root.tsx`:

```
{ name: "viewport", content: "width=1100" }
```

Google crawls and ranks with a mobile user agent. A hard-coded 1100px viewport tells every mobile browser to render the desktop layout scaled down. Even where the design still looks acceptable, this reads to Google as a non-responsive page and puts every mobile Core Web Vitals and usability signal at risk — tap targets, font scaling, layout shift.

**Fix:** move to `width=device-width, initial-scale=1` and let the CSS handle breakpoints. This is not a one-line change — the design was built against a fixed canvas and will need mobile breakpoints audited page by page. It is still the highest-leverage SEO work available.

#### P0 — No favicon

`/favicon.ico` returns 404 and no `<link rel="icon">` exists anywhere in the head. Google will not show a site icon next to the search result, which measurably suppresses CTR on branded queries — where nearly all current traffic comes from.

**Fix:** add `public/favicon.ico` plus a 512×512 PNG, and link both from `__root.tsx` (`rel="icon"` and `rel="apple-touch-icon"`).

#### P1 — Non-canonical hosts still return 302

Previously verified:

- `http://savorsunrise.com` → **302** → www (should be 301)
- `https://savorsunrise.com` → **302** → www (should be 301)
- `http://www.savorsunrise.com` → 301 ✓

A 302 tells Google the move is temporary, so link equity does not consolidate onto the www host. Semrush confirms the symptom: **every ranking URL it reports is the non-www variant** (`https://savorsunrise.com/`, `/products`, `/products/60mg-blueberry-lemonade`). The index is still anchored to the wrong host.

This lives above the application layer — it's the Lovable custom-domain redirect setting, not repo config. It needs a support request to switch `savorsunrise.com` from 302 to 301. DNS is correct and needs no change.

#### P2 — Thin, non-descriptive page titles

Current titles are brand-first and keyword-free:

| Route | Current | Suggested |
|---|---|---|
| `/products` | `Products · SUNRISE` | `THC Seltzers — 10mg & 60mg Delta-9 · SUNRISE` |
| `/find` | `Find · SUNRISE` | `Where to Buy THC Seltzer Near You · SUNRISE` |
| `/faq` | `FAQ · SUNRISE` | `THC Seltzer FAQ — Dosage, Effects & Legality · SUNRISE` |
| `/about` | `About · SUNRISE` | `About SUNRISE — Family-Owned THC Seltzer, Route 66` |
| `/contact` | `Contact · SUNRISE` | `Contact SUNRISE — Wholesale & Press Inquiries` |

The homepage title (`SUNRISE · Refresh the way the world drinks.`) is a brand slogan with zero category signal. Consider `SUNRISE — Hemp-Infused THC Seltzer | Delta-9 Delivered`.

PDP titles are the strongest on the site (`Lemonade · 10mg THC · SUNRISE`) — that pattern should propagate upward.

#### P2 — `/products` meta description understates the catalog

The active description covers only 10mg and 60mg; the 30mg tier is live again but the copy was never restored after the potency-cleanup revival (the original line is still commented out at `src/routes/products.tsx:29`).

#### P3 — No `twitter:card`

There are no Twitter tags anywhere. X falls back to OG in most cases, but an explicit `twitter:card: summary_large_image` on `__root.tsx` guarantees the large-image treatment.

#### P3 — No `og:image` on leaf routes

Only the root default OG image exists. PDPs have real product photography that would perform far better in shared links — worth wiring the can image into each PDP's `og:image` / `twitter:image`.

#### P3 — Sitemap omits `lastmod`

Correct as-is (no authoritative per-page timestamp exists), just noting it's a deliberate omission, not a gap.

#### P3 — No `llms.txt`

Not required, and AI crawlers already get the markdown rendering. Optional add if AI-search visibility becomes a priority.

The site ranks at positions 40–78 for these because Google can find *no better* match for the word "sunrise" plus the beverage context, not because the pages are relevant.

**Diagnosis:** the site owns its brand name and nothing else. 100% of measurable traffic lands on the homepage. `/products` ranks for six keywords with zero traffic share. Only one PDP ranks at all.

### Competitors

Semrush's auto-discovered competitor set is mostly name collisions (`sunrisebeverage.net`, `sunrisebeverages.co.uk`, `sunrisemountainfarms.com`) — further evidence the site is categorized by its brand word, not its category. The one real signal: `alohawagon.com` pulls an estimated 1,643 visits/mo off 255 keywords. That is what content breadth in this space buys.

### Backlink profile — needs cleanup

22 referring domains. The legitimate ones are good and on-topic:

- `hempbeveragealliance.org` (22 AS)
- `hempbeverageexpo.com` (23 AS)
- `growthzoneapp.com` (41 AS)
- `blackrivertraders.com` (16 AS)

The rest are link-farm spam — `backlinksplace.site`, `atomizelink.icu`, `quero.party`, `portailorange.net`, `ready.pro`. The anchor text confirms it:

> "high quality dofollow backlinks da 50 pa 40 premium pbn network service savorsunrise.com rank first page google fast seo link building buy backlinks online cheap" — **8 backlinks across 5 domains**

> "thanks to fiverr, savorsunrise.com traffic doubled from 5k to 10k visitors 🚀"

Someone either bought links or the domain is being used as a demo target by link sellers. Google generally ignores this rather than penalizing, but it dilutes the profile and can trigger manual review. **Recommendation:** file a disavow for those domains in Search Console once GSC is connected.

## 4. Recommendations, in order

### Immediate (this week)

1. **Add a favicon.** Half a day. Directly improves branded CTR, which is where all current traffic is.
2. **Request the 301 fix** for the non-www host from Lovable support. Until this ships, link equity is split across two hosts.
3. **Connect Google Search Console** to this project. Right now there is zero first-party data on impressions, queries, or coverage — every diagnosis above is inference from third-party estimates.
4. **Rewrite titles and meta descriptions** per §2, P2. Two hours of work.
5. **Restore the 30mg tier** in the `/products` description.

### Near-term (this month)

6. **Fix the viewport.** Move to `width=device-width` and audit each route's mobile breakpoints. This is the biggest technical lever and the biggest effort — plan it as a project, not a patch.
7. **Build a category page** targeting "thc seltzer" / "thc drinks" — an educational hub, not a product listing. What is a THC seltzer, how much is a 10mg vs 30mg vs 60mg dose, onset time, comparison to alcohol, legality. Link from the nav.
8. **Expand `/faq` against real question volume.** The question keywords are sitting there unclaimed: "how long does thc seltzer last", "how long for thc seltzer to kick in", "does thc seltzer show up on a drug test", "does thc seltzer have alcohol", "what is thc seltzer". Each is 30–210/mo, low competition, and the FAQPage schema is already wired.
9. **Turn `/find` into a local SEO asset.** "thc drinks near me" is 12,100/mo. A single "available in nine states" page cannot capture that. Per-state pages (`/find/oklahoma`, `/find/texas`) with real retailer names and addresses, plus `LocalBusiness`/`Store` schema, is the standard play and it works.

### Ongoing

10. **PDP `og:image`** per product.
11. **Disavow the spam domains** once GSC is connected.
12. **Earn 10–20 real links** — hemp beverage directories, local Tulsa/Oklahoma press, Route 66 and family-business angles, retailer partner pages, industry association listings. Authority Score 8 → 25 is the difference between "cannot rank for KD 45" and "can, with good content."

## 5. What not to worry about

- **Sitemap, robots, canonicals, SSR** — all correct. Don't touch them.
- **The `noindex` on `/social`, `/event-signup`, `/hbe`** — intentional and right.
- **FAQPage schema** — keep it even though the rich result was retired; it still feeds AI answers.
- **Missing `lastmod`** — correct omission, not a defect.

---

## 6. The honest read

This is a well-built site with a marketing problem, not a technical one. The engineering discipline is visible in the code — clean route metadata, real structured data, deliberate indexing decisions. But the site talks about SUNRISE to people who already know SUNRISE, and search demand for the brand is roughly 700 searches a month total. Category demand is over 130,000.

The gap between those two numbers is the entire opportunity, and it closes with content and links, not with head tags.
